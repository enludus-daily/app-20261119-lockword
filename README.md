# カギことば / Lockword

> App Store 名：**カギことば：クロスワード脱出** / **Lockword: Crossword Escape**
> enludus-daily の 2026-11-19 のアプリ（監督の指示 daily-ideas #37・題材の予定 #36 の 11/19 分）。Bundle ID `com.enludus.daily.014`。

夜の古い屋敷に閉じこめられた。部屋の物（肖像画・長持ち・柱時計・金庫…）それぞれに小さなクロスワードが刻まれていて、**解いた言葉がそのまま道具になる**。「カギ」を解けば鍵が手に入り、鍵のかかった長持ちが開く。物の盤の「印のマス」の文字を 4 つ集めて並べると、最後の扉が開く。

## だれの・どう使うか

- クロスワードが好きだけど、新聞の大きな盤は重い人。脱出ゲームが好きだけど、総当たりの謎解きで詰まりがちな人
- 1 部屋 10〜15 分（物 4 つ・言葉 16）、今日の小部屋 5 分（言葉 5）。寝る前に 1 部屋

## 遊び

- **部屋**：真ん中に扉、左右に物が 2 つずつ。物をタップするとクロスワードが開く
- **答えが道具になる**：各盤の「道具の語」（カギ・ロウソク・ハグルマ・ムシメガネ・ユビワ・コイン・チズ・ラシンバン）を解くと道具がトレイに入り、その道具が要る物の錠が外れる（1 → 2 番目、3 → 4 番目）
- **最後の扉**：盤の真鍮の丸のマスの文字（扉の文字）が文字盤に入る。4 つそろったら、カギの文（「物語はここから。最初の一歩」）を手がかりに並べ替えて扉を開ける（ハジマリ / LORE）
- **入力**：大きなマスと、その語の文字＋まぎらわしい文字を混ぜた 8〜10 個の木の札。同じマスを 2 回押すと縦横が切り替わる
- **ヒント 3 段階**：1 文字 → 意味（もう一つのカギ）→ 答え（Pro。無料でも 1 回だけ試せる）。ヒントが少ないほど星が増える
- **日本語と英語は別の問題**：日本語はカタカナのクロスワード（小さい字は大きく書く決まり）、英語は英語で成り立つクロスワード（LORE / TUNE / STAR / TIME）。直訳しない

## 毎日開く理由

1. **今日の小部屋**：毎日 1 つ、5 語のクロスワード（全員同じ）。毎晩 21 時の知らせ（設定でオン）
2. **続けた日数**（ろうそくの数）と、4 週間のマス（記録）
3. **部屋の物語**：4 部屋がつながり、時計塔から外へ出て終わる。出た部屋は最速と星を更新できる
4. **共有カード**：答えを書かない、扉と封蝋のカード

## 世界観

- このアプリでは〔クロスワードのマス〕が〔部屋の物に刻まれた羊皮紙の盤〕になり、〔答えの言葉〕が〔真鍮の道具〕になる
- 世界：夜の古い洋館の書斎。暗い胡桃材の羽目板・真鍮の金具・ランプの温かい光・羊皮紙のマス。題字と文字はセリフ（日本語は明朝）。画面はダークに固定（夜の室内）
- 前日までのアプリとの違い：うおさがし（明るい池と蓮の葉）・しめきりディフェンス（明るい木のテーブル）などの明るい地と違い、**暗い地・真鍮・羊皮紙・セリフ**。主役の部品はアーチ形の扉と文字盤
- 絵は全部 Canvas と Path（肖像画・長持ち・本棚・机とランプ・蓄音機・金庫・暖炉・柱時計・望遠鏡・地球儀、道具 8 種、扉、窓、封蝋）。外部の画像なし

## 手応えの表

| できごと | 動き | 振動 | 音 |
|---|---|---|---|
| 押す（マス・札・物） | 0.94 倍に縮む | selection | 木の札のコツッ |
| 1 文字入る | マスの文字がフェード、次のマスに真鍮の枠 | impact light 0.6 | コツッ |
| 語が解けた | その語のマスが先頭から 55ms ずつ 1.16 倍に弾む・真鍮色になる | impact medium | 真鍮の鈴 2 音 |
| 道具の語が解けた | 道具がトレイに飛び込む（scale 0.3→1）・知らせ | impact heavy | 小さな鈴 4 つの連なり |
| 違う（語が埋まったが違う） | その語のマスが横に揺れる（-7,6,-5,4,-2,1,0）・文字が消える | error | 低い木の音 2 回 |
| 鍵が要る物を押した | 物が横に揺れる・「〇〇が要る」 | error | にぶいガチッ |
| 錠が外れる | 物が -4°→3°→0° に揺れてから盤が開く | impact rigid | カチャリ |
| 盤が全部解けた | 扉の文字の知らせ・物に光が当たる・印の文字の札 | success | 文字盤が回る音 |
| 扉が開いた（脱出） | 封蝋の手紙が回りながら現れる・真鍮の火の粉（固定の乱数・2.4 秒） | success | 鐘と和音 |
| 場面の切れ目 | 部屋に入ると物語のカード、扉は重い音 | — | 扉のきしみ・紙をめくる音 |

動きを減らす設定では、揺れ・弾み・火の粉を止める。

## デモで見せる流れ（起動引数 `-demo`、約 18 秒）

1. 広間 → 第一の部屋に入り、物語のカード
2. 肖像画のクロスワードを解く。最後に「カギ / KEY」が解けて鍵がトレイに入る
3. 鍵のかかった長持ちを押すと、錠が外れて次の盤が開く

## 開発

- 問題を直す：`content/ja.json`・`content/en.json` を直して `python3 scripts/build-puzzles.py`（`App/Sources/Model/PuzzleData.swift` を作る）
- 画面の言葉：コードの `tr("日本語", "English")` から `python3 scripts/gen-strings.py` で `Localizable.xcstrings` を作る
- アイコン：`python3 scripts/make-icon-door.py`
- ビルドとテストは CI（`.github/workflows/ci.yml`）
